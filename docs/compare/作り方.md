# 比較用の画面写真の作り方（T08）

`/compare/` の左に出す「スプレッドシートの時」の画面写真（`src/assets/compare/sheet-before.png`）の作り方。
元のデータは `docs/compare/before_sheet.csv`（要件定義書7章「スプレッドシートの時」の11行。値はすべて架空）。

## 中身（要件定義書7章のとおり）

- 7章の架空の10件に、**2つの失敗** を入れた11行
  1. 清水 大輔さんが2行（電話で受けた行と、フォームから来た行。どちらも 12/19・2人）
  2. 工藤 誠さん（2人）が、12/12 に移したはずなのに 12/05 のまま。12/05 が 加藤4人＋木村4人＋工藤2人＝**10人**（定員8人を超える）
- 状態は列で持たず、**行の色だけ** で分ける（色の意味は人が覚えている、という「前」の姿）

| 状態 | 色 | Excel で塗る色（RGB） |
|---|---|---|
| 新規 | 無色（白） | 255, 255, 255 |
| 連絡済み | 黄 | 255, 242, 204 |
| 確定 | 緑 | 226, 239, 218 |
| 完了 | 灰 | 217, 217, 217 |
| キャンセル | 赤 | 248, 203, 173 |

- CSV の最後の列「塗る色」は、どの行を何色に塗るかの指示。**シートには写さない**（写すのは「受付日・希望日・お名前・人数・連絡先・ご要望・メモ」の6列）

## 手で作るとき（Excel）

1. Excel で新しいブックを開く（ほかのファイルが写らないように、新しいブックで作る）
2. A1 から右へ、見出しの6つ（受付日／希望日／お名前／人数／連絡先／ご要望・メモ）を入れる
3. 表全体（A1:F12）を選び、書式を「文字列」にしてから、CSV の値を1行ずつ入れる（`10/24` が日付に変わらないように。人数の列だけは数値でよい）
4. A1:F12 の書体を Meiryo（メイリオ）または游ゴシック、12pt にする。見出しの行は太字
5. 各行を「塗る色」の列のとおりに、A〜F 列まで塗る（上の表の RGB）。無色の行は白で塗っておく（塗らないと、画像にしたとき透明になり黒く出ることがある）
6. 罫線は「格子」、色は薄い灰。人数の列は中央揃え
7. 列を選んで幅を自動調整し、少し広げる（`#####` が出ないこと）。行の高さは 24pt くらい
8. A1:F12 を選び、「コピー」→「図としてコピー」（画面に合わせる／図）で写し、画像として保存する。**ブックは保存しない**
9. 画像を幅 1200〜1600px・500KB 以下にして、`src/assets/compare/sheet-before.png` に置く

## 自動で作るとき（今回 T08 で行った方法）

PowerShell から Excel を COM で動かした（Excel は画面に出さない・設定は変えない・ブックは保存しない）。

1. `before_sheet.csv` を `Import-Csv -Encoding UTF8` で読み、新しいブックの A1:F12 に書く（人数だけ数値、ほかは文字列）
2. 上の色・書体（Meiryo 12pt）・罫線・列幅（自動調整＋2）・行の高さ（24pt）を付ける
3. `Range("A1:F12").CopyPicture(xlScreen, xlPicture)` で使っているセルの範囲だけを図として写す
4. その範囲と同じ縦横の比の一時的なグラフ（ChartObject、背景は白）を作って貼り、`Chart.Export(..., "PNG")` で書き出す。幅 1400px になるように、グラフの大きさを決める（この PC では 1pt が 2px で書き出された）
5. ブックを保存せずに閉じ、`Quit` して、立ち上げた Excel が残っていないことを確かめる

## 確かめること（要件定義書12章 T08）

- ① 11行・清水さんの2行・12/05 の10人分（4＋4＋2）・色塗りが写っている
- ② アカウント名・メール（nao さんの）・ほかのファイル名・タブ・リボンが写っていない（セルの範囲だけ）
- ③ 幅 1200〜1600px・500KB 以下
- ④ 375px で表示して字が読めるか（意地悪QA に写真で判定してもらう）。読めなければ、問題の行だけを切り抜いた `sheet-before-sp.png` を作るかを nao さんに相談する
